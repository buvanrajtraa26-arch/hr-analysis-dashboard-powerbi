#  HR Analytics Dashboard - Power BI

##  Project Overview
This project is an **HR Analysis Dashboard** developed using **Microsoft Power BI** to analyze and monitor key human resource metrics.  
The dashboard provides insights into **employee demographics, attrition, department-wise distribution, and workforce trends** to support data-driven HR decisions.

This project demonstrates practical skills in **data modeling, DAX, and interactive dashboard development**.

---

##  Project Objectives
- Analyze overall employee strength and attrition  
- Understand workforce distribution by **gender and department**  
- Identify trends related to **age and experience**  
- Enable interactive analysis using filters and slicers  
- Build a professional HR dashboard using Power BI  

---

##  Tools & Technologies
- Microsoft Power BI  
- Power Query (Data Cleaning & Transformation)  
- DAX (Data Analysis Expressions)  
- Microsoft Excel  
- GitHub  

---

##  Dataset Information
The dataset used in this project contains HR-related employee data, including:
- Employee ID  
- Gender  
- Age  
- Department  
- Job Role  
- Education  
- Monthly Income  
- Attrition  
- Years at Company  

*This dataset is used for learning and portfolio demonstration purposes only.*

---

##  Dashboard Pages
The Power BI report consists of **two pages**:

###  Page 1: HR Overview
- Total Employees  
- Active Employees  
- Attrition Count and Attrition Rate  
- Gender-wise employee distribution  
- Department-wise employee analysis  

###  Page 2: Detailed Employee Analysis
- Age group distribution  
- Experience (Years at Company) analysis  
- Attrition analysis by department and job role  
- Interactive slicers for dynamic filtering  

---

##  Power BI Features Used
- Calculated Columns  
- Measures using DAX  
- KPI Cards  
- Bar Charts, Pie Charts, and Tables

- Data Modeling and Relationships
